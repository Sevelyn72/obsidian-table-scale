# Table Scale

拖动 Markdown 表格右侧外边缘，可以单独拉宽或收窄表格，文字大小保持不变。拖动下侧或右下角，可以让整张表格、文字和公式一起缩放。宽度和比例分别保存，阅读视图和实时预览共用记录。

## 功能

- 右侧外边缘左右拖动，单独调整表格宽度，文字和公式大小不变。
- 下侧外边缘上下拖动、右下角左右拖动，控制整张表等比例缩放，范围为 50%–150%。
- 双击右侧恢复自然宽度，双击下侧恢复 100% 比例，双击右下角恢复宽度和比例。
- 松开鼠标时保存，重新打开 Obsidian 后恢复。
- 表格内部仍可正常选字和编辑单元格。
- 不同表格分别记录，同一张表在多个窗格中同步。
- 在 Obsidian 内移动、重命名文件或文件夹时，迁移对应记录。

## 安装与要求

要求桌面版 **Obsidian 1.13.7 或更新版本**。主要测试平台为 Windows，macOS 和 Linux 尚需进一步手动验证。暂不支持手机端。

需要手动安装时，可以使用构建或发布得到的三个安装文件：

1. 在仓库中创建 `.obsidian/plugins/table-scale/`。
2. 将构建或发布得到的 `main.js`、`manifest.json`、`styles.css` 复制进去。
3. 重新加载 Obsidian，在 **设置 → 第三方插件** 中启用 **Table Scale**。

升级时保留原有 `data.json`，不要用其他仓库的记录覆盖它。

本地开发工程还提供 `node scripts/install-local.mjs <已有插件目录>`：先备份将被替换的文件，再复制构建产物和开发文件，保留原仓库的 `data.json`、`node_modules` 和 Git 历史。使用前先退出 Obsidian，复制后重新打开。

## 使用

在阅读视图或编辑模式的**实时预览**中打开普通 Markdown 表格。光标靠近右侧外边缘时，会变成左右箭头；按住左键向右拉，表格变宽，文字大小不变，松手后保存宽度。

需要文字、公式和表格一起变大或变小时，拖动下侧或右下角。缩放后再调整宽度，会保留当前的字体比例。向左收窄时，表格的最小宽度仍会受到单元格内容约束。

右下角保留原来的左右拖动方式。表格内部的单元格边框仍交给原生编辑器处理。需要重新关联已渲染的表格时，可在命令面板运行**刷新表格缩放**。

键盘操作：右侧边缘获得焦点后，方向键每次调整 20 像素宽度，**Home** 恢复自然宽度；右下角获得焦点后，方向键按 5% 调整比例，**Home** 恢复宽度和比例。提示和命令会跟随 Obsidian 语言：中文环境显示简体中文，其他语言显示英文。

可使用[示例笔记](examples/tables.md)测试。纯源码模式只显示 Markdown 字符，没有可拖动的排版表格。

## 数据与隐私

布局保存在当前仓库的 `.obsidian/plugins/table-scale/data.json` 中，记录仓库内的相对文件路径、表格标识的哈希、比例和可选宽度，不复制笔记正文。旧版第 1 版数据格式中的比例可继续读取，首次修改布局后保存为第 2 版格式；旧插件不支持新的数据格式。

插件不联网、不收集遥测，也不访问仓库外文件；不会向 Markdown 原文插入标签或样式。不同仓库分别保存，单独复制笔记不会自动带走缩放比例。

## 已知限制

- 表格使用“文档路径、标准化表头、相同表头的出现顺序”识别。修改普通单元格或在表格前插入段落可保留记录。修改表头，或插入、删除、调换多张相同表头表格的顺序时，可能需要重新设置比例。
- 支持普通 Markdown 表格。原生 HTML 表格、复杂嵌套及第三方插件生成的表格暂不在支持范围内。
- 实时预览依赖 Obsidian 的原生表格结构，主题、其他表格插件或 Obsidian 更新可能影响兼容性。
- 缩放比例是本插件的显示偏好，其他 Markdown 阅读器不会读取这些记录。
- 记录文件无法读取或根格式不兼容时，插件会保留原数据，并在该次加载中停止启用缩放。请先备份，再修复或重命名 `data.json`，然后重新加载插件。

## 开发

推荐 Node.js 24 LTS，最低 22.13，使用 npm。

```sh
npm ci
npm run check
npm run dev
```

`npm run check` 会检查 ESLint（零警告）、回归测试、严格类型、生产构建和发布信息。`npm run package` 还会将三个安装文件和本地 SHA-256 校验值整理到 `dist/<版本号>/`。

发布工作流会为安装文件生成 GitHub 构建来源证明，草稿 Release 仅附带 `main.js`、`manifest.json` 和 `styles.css`。校验文件留在本地使用。

运行时使用 Obsidian 自带的 Obsidian API 和 CodeMirror，不把它们重复打进插件。开发依赖、本地记录和构建产物已加入 Git 忽略规则。

更多信息见[开发说明](CONTRIBUTING.md)、[手动验收](tests/manual.md)、[更新记录](CHANGELOG.md)和[发布步骤](docs/PUBLISHING.md)。
